# frontend

Aquí irá la SPA React + TypeScript (Vite, Tailwind CSS, React Router, TanStack Query y
oidc-client-ts), según [design.md](../design.md) §2 y §8. Se publicará en un bucket S3
privado detrás de CloudFront con OAC.

Todavía no se ha creado. Mientras tanto, el backend sirve páginas HTML simples solo en
desarrollo local, para comprobar los endpoints (ver [backend/README.md](../backend/README.md)).
